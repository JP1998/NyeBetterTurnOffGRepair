
# Nye Better Turn off Guild Repair

...or the guild will go broke. Seriously, Nye, you gotta remember!

## Features

Reminds Nye to turn off guild repair when entering a current raid in a guild group, and reminds her to turn them back off if she is outside a raid and has guild repair turned on.

## Installation

This addon will be available from its [Wago Addons page](https://addons.wago.io/addons/nyebetterturnoffgrepair), its [CurseForge page](https://www.curseforge.com/wow/addons/nyebetterturnoffgrepair) as well as through [GitHub releases](https://github.com/JP1998/NyeBetterTurnOffGRepair/releases). Furthermore you can download the source code directly from the [GitHub repository](https://github.com/JP1998/NyeBetterTurnOffGRepair).

I've chosen these platforms because they are the ones I personally use, and at this time I don't see a reason to create releases for other platforms, as there is no demand. Nonetheless, I understand some people also use WowInterface or CurseForge, so if you'd like me to create releases on any other addon platform please [create an issue on GitHub](https://github.com/JP1998/NyeBetterTurnOffGRepair/issues/new) and I'll look into it.
